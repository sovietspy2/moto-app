# moto-app

A simple HTML + JavaScript web app scaffold.

## Files

- `index.html` — app shell and markup
- `styles.css` — simple responsive styling
- `app.js` — interactive JavaScript logic
- `package.json` — helper script to run a local server

## Run locally

1. Open `index.html` directly in your browser, or
2. Run `npm start` and open `http://localhost:3000`
